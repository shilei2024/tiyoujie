# ADR-0007：私图、校对历史和首个 OCR 费用入口

日期：2026-10-24。状态：已实施本地路径；真实外部能力与质量 BLOCKED。

用户连续要求继续开发，授权推进 Phase 3 的本地可审查实现。原阶段说明作为需求资料，不替用户授权公开部署、发真实资料或进入 Phase 4。此前缺配置和发布缺口继续分别记录，不妨碍本地实现。

私图不经过公开媒体路径。每次授权读取替代当前不需要的分享签名链接，避免长期链接扩散；前端临时图片在离页释放。清单先于文件写入，回滚后及级联删除后仍可清理。数据库触发器约束同孩子图片引用、OCR 模式/快照不可变、当前题干必须同题且已确认、历史版本不可覆写。

OCR 只是生成未确认文本候选，手动校对另建版本；不自动覆盖人工确认题干。识别提示使用独立最小模板 `ocr-transcribe-v1`，仅要求转录和受限 JSON；不把 PRD 或研发说明作为系统提示。Phase 4 的数学分析/纠错模板仍未实现。

平台 OCR 是首个可能发生平台费用的入口，所以在此阶段实现原子预占、累计/月/日/家庭硬预算、次数配额、账本、Outbox、Worker 重检、未知费用熔断。BYOK 固定绑定自己的凭证版本，账目与平台隔离，禁止隐式回退。全球策略锁以较低吞吐换取首版可审查的一致性；后续扩容必须保持所有预算窗口的同一事务语义。

没有凭证、有效费用上界、隐私条款和真实样本时默认禁用，不放入“可用”模型或试用次数种子。合成单元测试/真实队列保护探针验证代码约束，不代替真实 OCR 验收。
