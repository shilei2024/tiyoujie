# ADR-0006：Phase 2 本地继续开发

日期：2026-10-22。状态：本地实施采用，发布限制不变。

Phase 1 功能通过，braces 公告没有补丁，依赖门禁失败。用户随后明确要求“继续进入下一步”，据此继续本地 Phase 2。该指令不等于接受漏洞风险、允许公开发布或授权部署。Phase 1 报告作为历史记录保留。

本阶段实现身份、家庭、孩子、授权、删除、密文凭证和功能权益。测试登录默认关闭，显式 dev 启动才能开放，部署配置拒绝测试登录。缺微信配置返回不可用，测试身份不能称为真实微信验收。

本地 HTTP 禁止提交凭证原值，前后端均检查；不信任客户端转发头。后台仅开放活动/限额/权益调整与超级管理员账号状态操作，不注册孩子、微信身份或凭证模型；后台权限不能跨家庭使用业务 API。补发命令检查操作员权限并记录原因。

活动默认草稿，基础限额显式配置；领取事务同时锁家庭和活动，配合唯一约束防重复/超发，期限按活动时区自然月计算。到期权限即时按服务端时间判断，不依赖任务准时运行。站内提醒不会自动续费或删除资料。

未启用实际 AI、收费接口或生效活动种子。真实微信、小程序真机、受信任 TLS 和供应商验证单列阻断，不自动进入 Phase 3。结果见 [阶段报告](../../acceptance/phase-2-report.md)。
