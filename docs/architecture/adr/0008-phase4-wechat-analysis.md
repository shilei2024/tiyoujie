# ADR-0008：微信小程序推进与分析任务复用

日期：2026-10-24。状态：本轮实施；外部联调和 UI 交互待验收。

用户再次要求继续开发，并强调微信小程序及已登录的本地开发者工具，随后提供项目 AppID。承接 Phase 3 的本地能力推进 Phase 4；用户提供的文档是需求资料，不作为发布或隐私外发授权。阶段中按 Esc 停止界面操作后继续代码和终端验证，没有绕过界面中断。

主客户端继续使用 uni-app 的 mp-weixin 产物。真实 AppID 写入 manifest，AppSecret 只允许后端私密配置；提供可复现 build/open 脚本，不上传或发布。不以开发者工具登录代替应用微信登录，不为本机模拟器关闭域名或 TLS 保护。缺后端地址时仅显示明确的本地界面预览。

分析复用已有事务预算、Outbox、lease 和账本，保持 OCR 与分析共同受限，避免分开实现后出现两套独立的全站预算。历史 OCRJob/OCRModel 命名保留以降低迁移风险，对外使用 task_type 区分。BYOK 的连接状态只更新绑定凭证版本，不额外发起隐式付费探测。

先实现已确认题干 + 年级 + 明确作答的文本分析，不隐式附带图片、昵称、答案参考或内部 UUID。解析绑定版本，根因是候选，缺作答不推断错误位置。独立 math-tutor-v1 / math-analysis-v1 分别管理模板与输出契约；提示按层揭示，完整解析需主动展开，修订保留原始历史，全部待核验。数学验证器仍为 Phase 5 范围。
