# ADR-0009：Phase 6 复习调度、题单与导出的取舍

状态：已采纳（2026-10-24）。适用阶段：Phase 6 及之后。

## 背景

Phase 6 需要题单、作答、间隔复习、趋势与基础导出。约束是：

1. 不引入新的第三方依赖，不调用任何 AI 服务，不产生按次费用。
2. 家长与学生的数据必须严格隔离；错题、答案与导出内容属于私人学习资料。
3. 发布门禁禁止“伪造准确率”“删除后仍可下载”“导出携带外链资源”等行为。
4. 目标是微信小程序为主、H5 家长端可用。

## 决策

### 1. 复习算法：确定性阶梯，而非自适应模型

采用固定阶梯 1/3/7/14/30/60/120 天，答对前进、不确定退一级、答错回到 1 天。理由：

- 可解释、可测试，能在不依赖外部服务的情况下给出可复现的 `due_on`。
- 不存在“模型漂移”导致复习计划悄然改变的问题。
- 与 Phase 6 的“样本不足不计算统计结论”原则一致：算法只做调度，不宣称掌握度预测。

放弃：SM-2 的 ease factor 浮点调整（难测试、对小学错题收益不确定）、任何模型生成的复习建议（成本与合规未解决）。

### 2. 日期口径：本地日历日 + UTC 存储

新增 `PRACTICE_TIME_ZONE`（默认 `Asia/Shanghai`）。`due_on` 是日期字段，由本地时区算出；`created_at` 等仍存 UTC。理由：家长理解的“明天复习”是本地日历日，若直接用 UTC 日期会在晚间出现一天的偏移。

### 3. 题单：快照，而非引用实时题干

题单项保存题干与答案快照，题库题只额外保存 ID + 修订号。理由：

- 复习材料需要稳定；家长改错题不应悄悄改掉孩子正在做的题单。
- 题库许可可能撤回，因此题库题在读与作答时重新校验来源可用性，不可用时隐藏内容（宁可少显示，不可越权显示）。
- 删除错题会级联移除题单项，避免“删除后仍能读到题干”。

### 4. 作答评分：结构核验优先，自评兜底，不伪装 AI 判卷

有结构化算式的题目用 `math_verifier` 自动比对；其余按用户自评记录，`unsure` 不计为正确或错误。理由：AI 判卷需要模型与费用，且无法离线验收；让系统“看起来会判卷”会误导家长。

### 5. 导出：渲染时生成 + 短期票据，不落盘

导出采用 10 分钟有效、可撤销的票据，下载时重新渲染 HTML/CSV。理由：

- 没有服务器端文件，天然满足“删除后拒绝访问”。
- 不需要对象存储生命周期策略，也不引入新的存储成本。
- HTML 自包含（CSP `default-src 'none'`、无外链），可直接打印为 PDF；CSV 带 BOM 并做公式注入防护。

放弃：服务端生成 PDF 二进制。当前环境无 PDF 库，引入会扩大依赖与字体授权面；浏览器的“打印为 PDF”在 H5 端可满足基础需求，PDF 能力留待 Phase 7 视部署条件评估。

### 6. 趋势：样本不足就不给百分比

总作答 < 10 次时 `sufficient=false`；单知识点 < 5 次时 `accuracy=null`。理由：少量样本的正确率会被误读为学习结论，违反发布门禁对“统计口径”的要求。

## 后果

- 正面：无新增依赖，全部逻辑可离线测试；导出与删除语义清晰；不会因模型或供应商变化而改变历史数据。
- 负面：复习调度不个性化；变式与判卷能力有限；导出仅 HTML/CSV，微信小程序内不能直接下载文件（需家长端 H5）。
- 需要在 Phase 7/8 复核：题库规模扩大后的检索性能、真实样本下的趋势口径、以及是否需要 PDF。
