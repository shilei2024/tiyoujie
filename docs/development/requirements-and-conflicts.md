## 发现的差异

| ID | 差异 | 本轮处理 / ADR 建议 | 风险和待确认 |
| --- | --- | --- | --- |
| C01 | PRD §12 只有 0–4；开发说明细分 0–8，Phase 1 含义不同 | 使用工程阶段 0–8，并保留 PRD 对应关系 | 仅统一编号，不删除需求 |
| C02 | PRD Phase 0 要真实接入原型；开发说明要求当前仅方案设计后停止 | 本轮只做设计，真实接入按 Phase 2–4 验收；报告 PARTIAL | 不把不存在的原型标成 PASS；下一阶段不依赖真实 Key |
| C03 | “Provider 失败降级”与禁止静默跨模式回退可能冲突 | MVP 失败返回错误，由用户重新明确选择模式和模型 | 不增加自动调用与费用风险 |
| C04 | 批量导入既出现在后台 P0，又在 P1 列出 Excel/CSV/JSON | P0 规划最小规范 JSON 预览/审核；Excel/CSV 适配和批量错误报表放 P1 | 产品确认可调整格式，不降低来源审核 |
| C05 | 匹配解释在 P1，但核心练习流程要求匹配理由 | P0 保存并展示知识点/题型等基础理由；复杂解释排序放 P1 | 不让没有理由的推荐进入首版 |
| C06 | PRD §11.4 单句费用文案可能被理解为所有 AI 费都由用户承担 | 两种模式分别展示：平台有限额承担 / BYOK 供应商账号承担 | 以 §7.4 完整混合模式为业务基线 |
| C07 | “孩子数据互相隔离”未定义学生与同家庭监护人的具体权限 | 监护人按授权范围管理；学生只可访问绑定孩子；家庭成员身份不等于全家读写权 | 见威胁模型权限矩阵 |

上述为本轮设计建议；涉及阶段重排的 C01/C02 不表示真实原型要求被免除。没有作出增加公开范围、自动费用或运营义务的选择。

## 可以继续开发的安全默认值

首次外发前分别记录监护人授权、服务商告知版本和调用模式；未授权不发起任务。无活动配置则不发权益，无有效预算或价格则平台 AI 关闭，无 Key 不调用 BYOK。活动、额度、预算均不预填业务数值或生效日期。

所有拥有者数据至少定位到家庭，儿童内容进一步限定到孩子；官方供应商端点预置，普通用户不能传 Base URL。未支持的数学验证返回 not_supported。到期不删除，读取/基础导出/删除历史数据不被会员过期阻断。

## 后续阶段需要的输入

Phase 1 无需真实 Key、微信资质或云服务器访问。Phase 2 真实登录需要微信配置；Phase 3 OCR 需要授权样本和对应模式凭证；Phase 4 真实 AI 及预算上线需要费用上限和价格配置；Phase 7 预发布需要具体服务器、域名、TLS、存储与责任主体的合规核实。不得在聊天中索取明文秘密。
