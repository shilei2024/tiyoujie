# 威胁模型

日期：2026-10-22。设计审查，不构成已实现的安全保证。资产包括儿童作业/答题、家庭身份、BYOK、平台 Key、预算、权利证据、导出及备份。

## 角色与对象权限

| 主体 | 允许范围 | 明确禁止 |
| --- | --- | --- |
| 未登录者 | 登录、公开非个人产品信息、最少 liveness | 任务/儿童/私图/凭证/权益/导出读取 |
| 家庭监护人 | 授权孩子范围内管理；家庭管理权另授 | 其他家庭、未授权孩子、其他成员 Key |
| 学生 | 绑定孩子的错题、作答和复习 | 兄弟姐妹数据、家庭成员管理、Key/预算/导出全家 |
| 题库编辑 / 审核员 | 分配的题库导入/权利/质量审核 | 用户私图与任何 Key 明文 |
| 运维管理员 | 元数据、成本、状态和审计；活动/预算需专权 | 默认浏览私人题目、调用他人 Key、明文回读 |
| Worker | 按任务作用域和当前授权完成指定操作 | 任意 URL/工具、跨户取数、改变账单来源 |

后台对私图支持访问采用有理由、限时、用户授权和独立审计。超级用户/root 的技术能力不能仅靠后台页面限制消除；实际生产应最小人员授权、独立审计和秘密访问控制。

## 数据最小化与外发

只要求昵称和可选年级，不要求学校、学号、真名、手机号或位置。上传前提醒裁掉身份，服务端去 EXIF；图片可能仍有姓名/条码，不能将 EXIF 去除等同脱敏完成。外发前人工确认裁剪区域和用途，必要时拒绝未清理身份区域。

原始 OCR/AI 响应在私有受限数据层保存必要版本，不进入日志；留存期限和第三方政策需公开试用前确认。撤回授权后阻止未发送任务；已发送请求的第三方留存删除能力需按供应商政策如实说明。

## 上线前责任核实

需要责任主体核实儿童个人信息规则/监护人授权、数据导出删除、供应商条款和跨境范围、域名/小程序备案与服务类目、隐私指引、AI 服务登记/备案及生成内容标识适用要求、题库版权。此处列待核实事项，不提供法律结论，不表示任何审批已完成。

## 剩余风险

单机不可高可用；供应商价格变动或控制台外用量可能超出内部估算；root 可触及运行时秘密；已发送调用不可完全撤销；原生签名 URL 在 TTL 内通常不能单独即时撤销。这些约束必须在实现和部署选择时明确，不能用通过单元测试消除事实边界。
