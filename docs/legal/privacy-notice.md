# 隐私文本（发布用）与事实依据

本文件提供三份可直接使用的文本：微信后台《用户隐私保护指引》填写稿、应用内隐私政策、
监护人须知。**每一句都对应代码里的实际行为**，并标注了依据位置，便于核对与后续维护。

状态：文本已备好，等待运营主体信息确认（见 [待确认项](#待确认项)）。
确认前，[发布门禁](../acceptance/release-gates.md) 中 G12「隐私与责任主体」保持 PARTIAL。

## 一、我们实际收集与不收集什么

| 数据 | 是否收集 | 实际字段 / 依据 |
| --- | --- | --- |
| 微信身份标识 | 收集 | 仅 `openid`（`AuthIdentity.subject`、`provider`、`app_id`），不获取头像昵称，不获取手机号 |
| 真实姓名 / 学校 / 班级 | **不收集** | 无对应字段 |
| 孩子昵称 | 收集 | `ChildProfile.nickname`（≤32 字，家长自填，可填化名） |
| 年级、学期、教材版本 | 收集 | `ChildProfile.grade / semester / textbook` |
| 错题内容 | 收集 | 题面文本（`Problem` 文本版本）与拍照图片（私有存储，经鉴权接口读取） |
| 作答与复习记录 | 收集 | `Attempt`、`ReviewSchedule`、`ReviewEvent` |
| 技术日志 | 收集 | 请求 ID、时间、客户端 IP（代理后取真实末跳，`client_ip()`）、状态码、耗时；不记录请求体与 token |
| 位置 / 通讯录 / 相册全量 / 设备标识 | **不收集** | 无对应能力调用 |

第三方外发：

- 平台侧 AI 解析与 OCR **默认关闭**（`AI_ANALYSIS_ENABLED`、`OCR_OUTBOUND_ENABLED`、
  `PLATFORM_AI_ENABLED` 均为关闭），关闭时不向任何外部服务发送题目内容。
- 只有监护人**单独同意** `deepseek` / `kimi` 后，才会把题目内容发送给对应服务商
  （`GuardianConsent.scope`）；撤回同意即停止外发，未同意时功能不可用，不会静默降级。

| 收集你的手机号 | 不收集 |
| 收集你的相册（媒体文件） | 使用，用于拍摄或选择错题照片；仅上传你主动选择的那一张 |
| 收集你的摄像头 | 使用，用于拍摄纸质题目；仅在你点击拍照时调用 |
| 收集你剪切板 | 不收集 |
| 收集你的麦克风 | 不收集 |
| 收集你的通讯录 | 不收集 |
| 收集你的设备信息 | 不收集 |
| 收集你的日志信息 | 使用，用于故障排查与安全防护 |

「其他」栏填写：

> 本小程序为家庭错题整理与复习工具。为实现登录识别，我们会获取你的微信 openid；
> 为保存孩子的学习档案，我们会记录家长填写的孩子昵称、年级、学期、教材版本；
> 为提供错题与复习功能，我们会保存你上传的题目照片、题面文字以及作答、复习记录。
> 我们不收集真实姓名、学校、手机号、位置、通讯录与设备标识。上述信息仅存储于
> 中国境内自有服务器，不用于广告推送，不对外共享。你可以随时删除错题或注销账号，
> 注销后相关数据不可读、不可恢复。联系方式：【运营者邮箱】。

## 三、应用内隐私政策（可直接渲染为页面）

**题有解隐私政策　版本 2026-10-v1　生效日期【待填】**

### 1. 我们是谁

本小程序由【运营者主体全称】（下称"我们"）运营。我们提供家庭错题整理、题单练习、
固定阶梯复习与导出功能。联系邮箱：【运营者邮箱】。

### 2. 我们收集哪些信息，为什么

1. **登录标识**：微信 openid。用于识别你的账号、维持登录状态。没有它无法区分不同家庭的数据。
2. **孩子档案**：昵称、年级、学期、教材版本。由家长填写，用于按年级组织题目与复习计划。
   昵称可填化名，我们不要求真实姓名。
3. **学习内容**：题目照片、题面文字、作答结果、复习记录。这是错题整理与复习提醒的必要输入。
4. **技术日志**：请求 ID、时间、IP、状态码、耗时。用于排查故障和拦截异常请求。

我们**不收集**：真实姓名、学校班级、手机号、位置、通讯录、相册全量、设备唯一标识、麦克风。

### 3. 我们如何使用这些信息

仅用于：完成登录、保存与展示你创建的错题与题单、计算复习计划、生成你主动发起的导出文件、
保障服务安全。**不用于个性化广告，不做用户画像，不向第三方出售或共享。**

### 4. 会不会发给第三方

默认**不会**。平台侧的 AI 解析与图片识别默认关闭，关闭状态下题目内容不离开我们的服务器。

若你（监护人）主动配置第三方模型服务（DeepSeek / Kimi）并**单独同意**外发，题目内容会发送给
对应服务商用于生成解析。你可以随时在应用内撤回该同意；撤回后立即停止外发，相关功能随之不可用，
不会以"降级但继续外发"的方式处理。

### 5. 存储在哪里，保存多久

存储于中国境内的自有服务器。数据保存至你删除或注销：

- 删除单道错题：记录立即删除、不再可读，对应的图片文件由后台清理任务在随后几分钟内删除。
- 注销账号：提交后立即锁定账号、撤销全部登录态；后台任务完成数据删除，删除后不可恢复。
  提交注销时你会获得一个查询凭据，可据此查询删除进度。

我们未对学习数据设置自动到期删除。若你希望更短保留期，可【运营者说明：配置与承诺】。

### 6. 你的权利

- **查看与更正**：应用内可查看并修改孩子档案、错题内容。
- **删除**：可删除单道错题、解除家庭成员、注销账号。
- **导出**：题单可导出为 HTML 或 CSV 文件（10 分钟内有效的下载链接）。
- **撤回同意**：可在应用内撤回监护人同意。

### 7. 儿童个人信息

本服务面向家庭使用，孩子的档案由监护人创建。我们要求监护人先阅读并同意
《监护人须知》后才可创建孩子档案；孩子本人不单独注册账号。监护人可随时撤回同意，
撤回后该孩子的档案与学习数据按删除流程处理。

### 8. 安全措施

- 全站 HTTPS（TLS 1.2+，HSTS 一年，禁止被嵌入，禁止 MIME 嗅探）。
- 登录态使用短期访问凭证 + 可撤销刷新凭证，服务端只保存哈希。
- 数据库与 Redis 不对公网开放，仅容器内网可达。
- 上传图片存于私有目录，只能通过鉴权接口读取，不提供公开直链。
- 管理后台与生产配置分离，生产环境关闭开发登录。

### 9. 政策更新

本政策版本号会随内容变更递增（当前 `2026-10-v1`）。重大变更会在应用内提示并重新征得同意。

## 四、监护人须知（对应 `notice_version = 2026-10-v1`）

> 在创建孩子档案前须展示，监护人确认后写入一条 `GuardianConsent(scope="profile")`。

1. 你是该孩子的监护人或已获得监护人授权。
2. 你为孩子创建的档案仅包含昵称、年级、学期、教材版本，请勿填写真实姓名、学校、班级。
3. 题目照片可能包含手写字迹。请避免拍摄含姓名、学号、校徽等身份信息的内容。
4. 平台默认不向任何外部服务发送题目内容。若你希望使用 AI 解析，需另行同意，
   并知悉题目内容将发送给你选择的模型服务商。
5. 你可以随时删除孩子的档案与相关数据，或撤回同意；撤回后相关功能停止，数据按删除流程处理。
6. 若你发现孩子信息被他人（如其他家庭成员）错误访问，可解除该成员或联系我们。
