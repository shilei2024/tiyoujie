## 1. 交付范围

| 能力 | 实现 | 关键约束 |
| --- | --- | --- |
| 题库导入 | `preview_import` / `commit_import`，单批 ≤ 20 题、48,000 字符 | 预览签名绑定操作者、内容摘要、来源 ID 与来源版本；10 分钟内复放去重 |
| 权利与来源 | `QuestionSource` 许可名称、授权证据、署名、使用条件、有效期、公开范围 | 未审核、缺证据、已过期或来源类型为 unknown/user_upload 一律不可用 |
| 数学核验 | `math_verifier` 支持有理数四则、一元一次方程、选项比对 | 不支持的题型返回 `not_supported`，不伪造通过 |
| 人工审核 | Django Admin 工作流：来源审核、机器核验、逐题审核 | 机器核验不会授权发布；人工需分别确认题干、建模、解析 |
| 检索 | 按知识点、关键词、年级、难度、题型、解题结构匹配 | 只返回可用来源；返回匹配理由；候选上限 200 |
| 变式草稿 | 四个方向：换数字、变条件、逆向、情境 | 只支持已核验算式；草稿私有、未验证、幂等写入 |

公开 JSON 输出沿用题库字段，来源证据、内部审核理由不进客户端。数据库触发器保护来源/题目内容变更后的审核失效，以及草稿与核验记录的不可覆写历史。
