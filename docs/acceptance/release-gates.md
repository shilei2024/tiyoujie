# 发布门禁

日期：2026-10-24。该文件定义全产品发布证据，不是通过证书。当前已推进 Phase 8：代码、测试、双端构建、本地恢复演练、生产编排合并、Caddy 边缘层本机演练通过；真实证书签发、真实主机发布、微信 AppSecret/真机与题库许可仍有缺口，**NO GO（公开发布）**。详细结果见 [Phase 8 报告](phase-8-report.md)、[Phase 7 报告](phase-7-report.md) 与 [发布报告](release-report.md)。

## 状态定义

- PASS：已实际运行且有可复现证据，说明适用范围。
- FAIL：已执行但不符合规则，必须修复。
- BLOCKED：缺样本、权限、凭证、配置或责任主体确认，无法完成该验收。
- NOT TESTED：尚未到实施阶段或未执行；不等于通过。
- 阶段交付可为 PARTIAL，但不能据此签署公开发布。

## OCR 与统计阈值
