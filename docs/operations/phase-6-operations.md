# Phase 6 运维：复习调度、题单与导出

日期：2026-10-24。

## 1. 新增配置

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `PRACTICE_TIME_ZONE` | `Asia/Shanghai` | 复习“今天”的时区；数据库仍存 UTC，`due_on` 为日期 |
| 题单上限 | 200/孩子 | 代码常量 `MAX_WORKSHEETS` |
| 题单容量 | 30 题 | 代码常量 `MAX_ITEMS` |
| 作答上限 | 20 次/题 | 代码常量 `MAX_ATTEMPTS` |
| 导出票据 | 10 分钟 | `EXPORT_MINUTES`；过期与撤销由 `410` 统一呈现 |
| 趋势窗口 | 8 周，最多 26 周 | 单次最多扫描 5000 条作答 |

`PRACTICE_TIME_ZONE` 变更会影响新写入的 `due_on`，已存在的日期不迁移。跨时区运营前先确认口径，避免同一天出现两次“今日到期”。

## 2. Celery

新增 beat 任务：

| 任务 | 周期 | 作用 |
| --- | --- | --- |
| `apps.practice.tasks.cleanup_export_tickets` | 3600 秒 | 删除过期或撤销超过 24 小时的导出票据 |

票据本身不存文件内容，清理只回收数据库行。Worker 停止不会泄露导出：下载时始终校验过期、撤销与对象存在性。

## 3. 数据库守卫

`practice_guard` 迁移（`0002_practice_guards`）安装触发器：

- 题单项的来源绑定、文本、答案、解析、知识点、算式与创建时间不可 UPDATE（题号重排除外）。
- 作答记录禁止 UPDATE（级联删除仍允许，以支持账号注销）。
- 复习判定记录禁止 UPDATE。
- 导出票据的 nonce、类型、孩子、题单、过期时间不可修改；`revoked_at` 只能从空值写入一次。

出现 `23514` 校验错误时应视为应用逻辑或越权写入，不允许通过关闭触发器绕过。

## 4. 监控与排障

| 现象 | 排查 |
| --- | --- |
| 复习队列长期为空 | 检查 `due_on` 是否被写成未来日期、时区配置是否被改动、错题是否已删除 |
| 到期数量突增 | 正常现象：答错会回到 1 天；确认是否有批量重置或导入 |
| 导出 410 | 票据过期（10 分钟）、题单/孩子已删除、账号无权或已撤销 |
| CSV 中出现 `'` 前缀 | 公式注入防护，Excel 会按文本显示；不要移除 |
| 导出返回 406 | 反向代理覆盖了 `Accept` 头；该接口仍需 DRF 内容协商，保留默认 `Accept` |

## 5. 备份与数据保留

- 题单、作答、复习计划、复习记录属于私人学习数据，随孩子档案与账号注销级联删除。
- 题库题目为共享数据，导出时按来源可用性重新判定；许可到期后历史导出的 HTML 仍可能存在于用户本地，产品文案需提示家长自行保管。
- 数据库备份需包含 `practice_*` 全表；不含任何导出文件（无服务器端文件产物）。

## 6. 容量与性能

- 复习队列：按 `(child_id, due_on)` 索引；单孩子规模在千级错题内可接受。
- 趋势：单次读取 5000 条作答上限；超出时应改为数据库侧按周聚合，不能静默截断后宣称完整。
- 导出：HTML/CSV 在请求内生成，受 gunicorn 15 秒超时约束；题单上限 30 题使响应保持在 KB 级。
