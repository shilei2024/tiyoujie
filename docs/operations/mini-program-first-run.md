# 小程序首次使用：登录、建家庭、加孩子

面向体验成员（家长）的操作说明，以及每一步失败时的判断依据。
真机操作前需先完成两件后台动作：**新账号服务器域名白名单**、**把 0.1.1 选为体验版**。

## 一、怎么进到小程序里

三种方式，任选：

1. **扫体验版二维码**：微信后台 → 管理 → 版本管理 → 体验版二维码（只有被加为体验成员/开发者的微信能扫开）
2. **微信搜索小程序名**「题有解」（前提是已发布，体验版不适用）
3. 之前打开过：微信首页下拉 → 最近使用的小程序

进去前先确认一件事：**该微信号在「成员管理」里**。不在的话扫二维码会提示无权限，而不是打开页面。

## 二、登录

首页标题下方就是登录区，只有一个按钮：**微信登录**。

点击后走的是微信静默授权，**不弹手机号、不要验证码、不填密码**：

```
uni.login() → code → POST /api/v1/auth/wechat-login/ → 后端用 code 换 openid → 建会话
```

首屏这段是设计如此，不是缺陷：**会话只存在内存里，小程序被关闭/重进需要再点一次「微信登录」**。
代价是每次多一次点击，收益是 access/refresh token 不落任何持久化存储。

### 登录不上时按这个顺序判断

| 现象 | 含义 | 处理 |
| --- | --- | --- |
| 按钮灰色，下方写「服务端尚未配置微信登录」 | 能力声明 `wechat_configured=false` | 服务端 AppID/Secret 未成对生效，查 `/api/v1/auth/capabilities/` |
| 提示「网络异常」，且服务端日志**一条请求都没有** | 服务器域名白名单没配 | 后台把 `https://tiyoujie.pxcore.com.cn` 加进 request / uploadFile / downloadFile |
| 返回 `WECHAT_NOT_CONFIGURED`（503） | 密钥为空 | 跑 `infra/deploy/rotate-wechat-credentials.sh` |
| 返回 `WECHAT_CODE_INVALID`（400） | 后端已正确调用微信，但 code 过期/被用过 | 重新点一次登录；持续出现需查 AppID 与 Secret 是否同一小程序 |
| 创建家庭弹「请先由管理员配置家庭与档案的基础限额」 | 库里的基础限额（`ResourcePolicy`）缺失，`SITE_NOT_CONFIGURED` | 正常发布不会出现（`deploy.sh` 会补齐）；手工修：`manage.py configure_limits --basic-children 3 --max-families 3 --reason "..."` |

「网络异常 + 服务端零日志」这一组合必须先怀疑白名单，而不是后端——
白名单没配时请求根本没离开手机，服务端不可能有记录。

## 三、创建家庭

登录成功后出现「我的家庭」面板。

1. 在输入框填**家庭名称**（1–40 字，比如「小明的家」）
2. 点 **创建家庭**

创建者自动成为该家庭的**所有人（owner）**，角色为监护人。用户可拥有多个家庭，
面板顶部用下拉切换；已有家庭时再建一个新的，会**自动选中新建的那个**（0.1.1 修复）。
家庭数量有上限，由权益配置里的 `max_families` 决定。

## 四、添加孩子档案

在「孩子档案」面板里：

1. **孩子昵称**（必填，≤32 字）——用昵称即可，不需要真实姓名
2. **年级**（可选，1–12 的整数，留空也允许）
3. 勾选 **「我已阅读，并以监护人身份同意」**（监护人告知版本 `2026-10-v1`）
4. 点 **保存学习档案**

三点要注意：

- 不勾告知就无法保存——未成年人数据必须有监护人同意留痕（`GuardianConsent` 表记录版本与范围）
- 年级只作为档案信息保存（数据库约束 1–12），**当前不参与自动组题**，留空不影响任何功能，之后可用「编辑档案」补
- 监护人可对每个孩子单独「管理授权」（撤回/恢复档案授权）；学生角色只能看，不能改

## 五、邀请其他家庭成员

「家庭协作」面板，仅 owner 可生成邀请：

1. 选一个**授权档案**（邀请只授予这个孩子，不是整个家庭）
2. 选角色：**学生（只读）** 或 **监护人（可管理）**
3. 点 **生成单次邀请**，得到邀请码（24 小时有效、一次使用）
4. 对方在被邀请的微信里打开小程序 → 登录 → 把邀请码填进「家庭协作」输入框 → 点 **加入家庭**

邀请码等同于访问凭证，只发给认可的人；过期或已用需重新生成。

## 六、接下来能做什么

首页四个入口：**我的错题本**（拍照/上传 → 人工校对题干）、**今日复习**（1/3/7/14/30/60/120 天阶梯）、
**练习题单**（组题、作答、导出）、**AI 设置**（自管服务凭证）。底部还有「申请注销账号」。
